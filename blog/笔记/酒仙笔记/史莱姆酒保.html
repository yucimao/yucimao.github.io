--- layout: zk title: 史莱姆酒保 nav_text: 史莱姆酒保 nav_url: 酒仙笔记 permalink: i/19238324 --- 制作酒的步骤：
  1. 按顺序将材料投入摇壶。
  2. 用木棒捶打4次。
  3. 摇匀。
史莱姆麦酒

带有弹性泡沫的基础酒馆饮品。
材料：青绿凝胶

甜味史莱姆果酒

带果香的低度史莱姆果酒，适合早期客人。
材料：青绿凝胶 + 花蜜凝露 + 晨叶露浆

蓝精拉格

蓝色史莱姆精华发酵出的清亮拉格。
材料：青绿凝胶 + 蓝露精华 + 潮旋晶盐

厚凝黑啤

口感厚重，泡沫稳定的黑啤。
材料：青绿凝胶 + 苔衣凝胶 + 蓝露精华

琥珀陈酿

带琥珀香气的中阶陈酿。
材料：青绿凝胶 + 晨叶露浆 + 琥珀晶核

花蜜史莱姆酒

花蜜甜香明显的温和酒水。
材料：青绿凝胶 + 草冠晶核 + 火种酵晶

冰晶苏打酒

杯壁会凝霜的冰晶气泡酒。
材料：青绿凝胶 + 冰晶液滴 + 水雾凝珠

熔胶热托蒂

热饮，入口有微微的熔胶暖意。
材料：青绿凝胶 + 熔胶结晶 + 火种酵晶

草冠蜜酒

用草冠核心催香的浓郁蜜酒。
材料：青绿凝胶 + 草冠晶核 + 潮旋晶盐

蓝雾鸡尾酒

蓝雾在杯口盘旋的观赏型鸡尾酒。
材料：青绿凝胶 + 蓝露精华 + 水雾凝珠

裂壳琥珀苦酒

带轻微矿物苦味的琥珀系酒水。
材料：青绿凝胶 + 裂岩琥珀壳 + 琥珀晶核

深蓝女王香槟

高压蓝泡带出细密持久的气泡。
材料：青绿凝胶 + 泡泡蓝露 + 月莲凝露

冰火史莱姆菲力普

冷热两段口感交替出现的调酒。
材料：青绿凝胶 + 冰晶液滴 + 熔胶结晶

琥珀烟熏威士忌

带烟熏味的高价烈酒。
材料：青绿凝胶 + 琥珀晶核 + 黑曜凝砂

王冠草地灵酒

草冠力量带来稳定的高端风味。
材料：青绿凝胶 + 花蜜凝露 + 潮旋晶盐 + 琥珀晶核

深池苦艾酒

深蓝池底香气浓烈，回味清冷。
材料：青绿凝胶 + 苔衣凝胶 + 潮旋晶盐 + 黑曜凝砂

熔琥白兰地

熔胶和琥珀核心共同蒸馏的烈酒。
材料：青绿凝胶 + 蓝露精华 + 熔胶结晶

弹星马天尼

杯中凝胶会像星点一样跳动。
材料：青绿凝胶 + 弹力凝胶 + 泡泡蓝露 + 溶胶结晶

雷光凝胶海波

蓝琥材料调出轻微电感的海波杯。
材料：青绿凝胶 + 水雾凝珠 + 雷鸣胶脂

古琥珀波特

厚重甜润，适合高阶客人的餐后酒。
材料：青绿凝胶 + 晨叶露浆 + 黑曜凝砂 + 火种酵晶

王冠霜露利口酒

草冠清香与冰晶凉意融合的利口酒。
材料：青绿凝胶 + 弹力凝胶 + 冰晶液滴 + 裂岩琥珀壳

女王凝胶桑格利亚

高阶蓝凝胶带来浓郁果香和层次。
材料：青绿凝胶 + 晨叶露浆 + 月莲凝露 + 雷鸣胶脂

熔岩史莱姆热红酒

寒冷地图客人最喜欢的热红酒。
材料：青绿凝胶 + 苔衣凝胶 + 月莲凝露 + 火种酵晶

秘藏史莱姆陈酿

多地图稀有材料调和出的秘藏陈酿。
材料：青绿凝胶 + 草冠晶核 + 裂岩琥珀壳 + 雷鸣胶脂

彩虹凝胶鸡尾酒

杯中呈现多层史莱姆凝胶色带。
材料：青绿凝胶 + 泡泡蓝露 + 冰晶液滴 + 雷鸣胶脂

酒馆大师特调

当前酒馆的旗舰特调，代表最高制作水平。
材料：青绿凝胶 + 花蜜凝露 + 蓝露精华 + 裂岩琥珀壳
